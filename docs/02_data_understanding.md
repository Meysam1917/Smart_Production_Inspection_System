# Data Understanding

## Dataset Source

PCB Defect Dataset — publicly available PCB defect detection dataset with six annotated defect classes.
https://www.kaggle.com/datasets/akhatova/pcb-defects

---

## Classes

- Mouse Bite
- Spur
- Missing Hole
- Short
- Open Circuit
- Spurious Copper
